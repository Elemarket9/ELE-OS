# Device pages

No handset has a page here. The first page, when the port starts, will be
`shiba.md` for the Pixel 8. It is not supported yet.

When a device is proposed, add `docs/devices/<codename>.md` using the record
and the checklist in [device support](../device-support.md). The page states
the device class and the tier the evidence actually supports. A flagship, a
mid-range phone, and an older low-RAM phone are all eligible. None is
implied by an empty directory.

The virtual product `ele_os_cf_x86_64` is documented with the overlay in the
repository root. It is Tier 0, and it has not been booted in a recorded run.
