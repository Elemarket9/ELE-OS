# Evidence

Measured results live in this directory. A file here is a transcript of
something that was actually run: host tests, a failed build with the host
limit that stopped it, a Cuttlefish boot, a paired timing, a device
checklist.

Do not add targets, estimates, or numbers copied from another project.
Cuttlefish results stay labeled as virtual. Handset results name the
codename and the device class (flagship, mid-range, or low-end / older).

[2026-11-20 host tests](2026-11-20-host-tests.md) records one pass of
`tests/run.sh`. [2026-11-20 Faith voice](2026-11-20-faith-voice.md) records
the voice policy checks and one host run of Pico and whisper.cpp. The
transcript did not match the sentence, and the wake phrase was not detected.
Nothing here yet records an AOSP build, a Cuttlefish boot, or a handset.
