# Packages and modules that ELE-OS products must not add.
# This is a build policy for this repository. It is not a measurement of
# RAM, storage, or battery, and it does not edit a phone's vendor image.
# A Treble GSI leaves the vendor image in place, so software already on
# that partition is outside this list.
#
# AOSP's generic system image is not on this list. AOSP WebView
# (com.android.webview) is not on this list. TalkBack built from
# google/talkback (Apache-2.0) is not on this list; its package name
# com.google.android.marvin.talkback stays allowed. The Play Store
# Accessibility Suite prebuilt is forbidden below.
#
# Lines are "module <Soong-or-make-module>" or "package <android-package>".
# module is the name a product makefile would put in PRODUCT_PACKAGES.
# package is the Android package name.
